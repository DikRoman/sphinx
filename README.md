# SPHINX - GTD Productivity System

Система управления задачами по методологии GTD (Getting Things Done).

## 🚀 Запуск приложения

### Способ 1: Локальный сервер (рекомендуется)

Используйте скрипт для автоматического запуска:

```bash
./start.sh
```

Или запустите вручную одним из способов:

**Python 3:**
```bash
python3 -m http.server 8000
```

**Node.js (http-server):**
```bash
npx http-server -p 8000 -c-1
```

**PHP:**
```bash
php -S localhost:8000
```

Затем откройте в браузере: `http://localhost:8000`

### Способ 2: Прямое открытие

Просто откройте файл `index.html` в браузере (двойной клик или через меню "Открыть файл").

⚠️ **Примечание:** При прямом открытии могут возникнуть проблемы с загрузкой модулей из-за политики CORS. Рекомендуется использовать локальный сервер.

## 📁 Структура проекта

```
SPHINX/
├── index.html          # Главный HTML файл
├── styles/
│   └── main.css        # Стили приложения
├── js/
│   ├── app.js          # Главный модуль приложения
│   ├── config.js       # Конфигурация
│   ├── storage.js       # Работа с localStorage
│   ├── gtd.js          # GTD логика
│   ├── kanban.js       # Kanban доски
│   ├── habits.js       # Трекер привычек
│   ├── content.js      # Библиотека контента (фильмы, книги, сериалы)
│   ├── calendar.js     # Календарь
│   ├── notes.js         # Текстовые заметки
│   ├── sticky-notes.js # Стикеры
│   └── gantt.js        # Диаграммы Ганта
└── start.sh            # Скрипт запуска сервера
```

## ✨ Возможности

- **Inbox** - Быстрый захват задач
- **Сегодня** - Задачи на сегодня
- **Области** - Управление жизненными сферами
- **Проекты** - Управление проектами с Kanban досками
- **Привычки** - Трекер привычек с календарем
- **Контент** - Библиотека фильмов, книг, сериалов
- **Календарь** - День, неделя, месяц с масштабированием
- **Заметки** - Текстовые заметки с блоками
- **Стикеры** - Перетаскиваемые цветные стикеры
- **Ганта** - Диаграммы Ганта для проектов

## 💾 Хранение данных

Все данные хранятся локально в браузере через `localStorage`. Никаких серверов или баз данных не требуется.
