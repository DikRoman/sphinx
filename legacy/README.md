# Архив SPHINX

- **`sphinx-gtd/`** — прежнее приложение (GTD, канбан, календарь, стикеры, Supabase). Открыть: [`sphinx-gtd/index.html`](sphinx-gtd/index.html) относительно корня репозитория на хостинге, например `https://…/legacy/sphinx-gtd/index.html`.

Корневой **`index.html`** теперь ведёт на **Ascension** — RPG-платформу самообучения (`js/rpg-*.js`, `styles/main.css`).
